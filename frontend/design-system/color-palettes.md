# 脑痒 - UI 设计系统

## 🎨 设计理念

**品牌定位**：智能辩论平台，象征思维的活跃与智慧的成长
**核心概念**："脑痒" = 思考的痒感，智慧的萌发
**情感基调**：专业、智慧、活力、现代

## 📋 配色应用规范

### 页面元素应用

| 元素 | 推荐配色 | 说明 |
|------|---------|------|
| 导航栏背景 | 主色 / 浅色模式白色 | 建立品牌识别 |

| 警告提示 | 警告黄 (#F59E0B) | 注意提醒 |
| 错误提示 | 错误红 (#EF4444) | 问题警示 |

## 🌙 深色模式适配

所有配色方案均需支持深色模式，主要调整：

| 元素 | 浅色模式 | 深色模式 |
|------|---------|---------|
| 页面背景 | #F8FAFC | #0F1117 |
| 卡片背景 | #FFFFFF | #1A1D24 |
| 输入框背景 | #FFFFFF | #252830 |
| 边框颜色 | #E2E8F0 | #2A2E3A |
| 主要按钮 | #3B82F6 | #60A5FA |
| 文本主色 | #0F172A | #F1F5F9 |
| 文本次色 | #475569 | #94A3B8 |

## ♿ 无障碍标准

| 要求 | 标准 | 实现方式 |
|------|-----|---------|
| 文本对比度 | 4.5:1 (普通文本) | 主体文本使用深色 |
| 大文本对比度 | 3:1 (≥18px/14px粗体) | 标题、按钮文字 |
| 非文本对比度 | 3:1 | 图标、按钮边界 |
| 焦点可见性 | 明确的焦点指示 | 2px outline，offset |

## 🎯 推荐默认方案

**方案1：科技蓝紫** - 建议作为默认配色
- 传达智慧与科技感
- 蓝色有助于集中注意力
- 渐变效果增强品牌识别

如需切换，可通过CSS变量快速替换：
```css
:root {
  --brand-primary: #3B82F6;  /* 替换为方案主色 */
  --brand-secondary: #8B5CF6;
  --brand-accent: #06B6D4;
}
```
