📖 使用指南

应用配色方案

通过CSS变量快速切换配色方案：

:root {
  --brand-primary: #3B82F6;
  --brand-secondary: #8B5CF6;
  --brand-accent: #06B6D4;
}

/* 切换为暖阳金方案 */
.theme-warm {
  --brand-primary: #F59E0B;
  --brand-secondary: #FBBF24;
  --brand-accent: #EA580C;
}

使用Logo

在HTML中引用Logo：

<!-- 标准版 -->
<img src="/brain-itch-logo.svg" alt="脑痒">

<!-- 简化版（小尺寸） -->

无障碍标准

颜色对比度要求：

/* 普通文本：4.5:1 对比度 */
.text-primary { color: #F1F5F9; }
.bg-dark { background: #0F1117; }
/* 对比度: 15.3:1 ✓ */

/* 大文本：3:1 对比度 */
.text-large { color: #94A3B8; }
/* 对比度: 4.7:1 ✓ */
